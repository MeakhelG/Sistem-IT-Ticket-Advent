Alur Lengkap: Dari Pelaporan hingga Penilaian Kepuasan

Memperlihatkan interaksi antara Staf Kantor (Reporter) dan Tim IT (Technician) termasuk catatan internal rahasia IT.

flowchart TD Start([Mulai: Staf Mengalami Kendala IT]) --> Form[Isi Formulir Tiket Kendala
Judul, Kategori, Prioritas, Lokasi] Form --> UploadCheck{Ada Lampiran
Foto/Screenshot?} UploadCheck -- Ya --> ValidateUpload[Validasi File Upload
Maks 5MB & MIME jpg/png/webp] ValidateUpload --> UploadPass{Valid?} UploadPass -- Tidak --> ErrUpload[Tampilkan Pesan Error Validasi] --> Form UploadPass -- Ya --> GenCode[Generate Kode Tiket Otomatis
Format: TKT-YYYYMM-XXX] UploadCheck -- Tidak --> GenCode GenCode --> SaveDB[(Simpan Tiket ke DB
Status: open)] SaveDB --> LogCreate[Catat ke ticket_logs:
Tiket Diajukan] LogCreate --> InboxIT[Tiket Muncul di Kotak Masuk Tim IT] InboxIT --> ITAction[Tim IT Memeriksa & Mengambil Tiket] ITAction --> UpdateProgress[Ubah Status: in_progress
Catat ke ticket_logs] UpdateProgress --> ThreadHub{Ada Kebutuhan
Diskusi / Balasan?} ThreadHub -- Ya --> CheckSender{Siapa yang Mengirim Pesan?} CheckSender -- Staf --> StafReply[Kirim Pesan Publik
is_internal = 0] CheckSender -- Tim IT --> ITNoteType{Pilih Jenis Pesan} ITNoteType -- Balasan ke Staf --> PubReply[Pesan Publik: is_internal = 0] ITNoteType -- Catatan Rahasia IT --> PrivReply[Catatan Internal: is_internal = 1
Hanya Terbaca Sesama IT] StafReply --> SaveReply[(Simpan ticket_replies
& Audit Log)] --> ThreadHub PubReply --> SaveReply PrivReply --> SaveReply ThreadHub -- Masalah Selesai --> ITSolve[Tim IT Input Catatan Solusi
Ubah Status: resolved
Timestamp: resolved_at = NOW] ITSolve --> LogResolved[Catat ke ticket_logs:
Status Diubah: Selesai Ditangani] LogResolved --> StafRating[Staf Menerima Notifikasi Selesai
Isi Rating 1-5 Bintang & Ulasan] StafRating --> SaveRating[(Simpan Rating ke DB
Status: closed)] SaveRating --> LogClosed[Catat ke ticket_logs:
Rating Diberikan & Tiket Ditutup] LogClosed --> End([Selesai: Arsip Knowledge Base])
Alur Pemrosesan Request Backend (Clean Architecture)

Pemisahan tanggung jawab: Browser → Autoloader → Router → Middleware → Controller → Service → Model → Database.

flowchart LR Req["Browser HTTP Request
(GET / POST / AJAX)"] --> Autoload["Front Controller index.php
+ PSR-4 Autoloader"] Autoload --> Router{"Router Switch
(page / action)"} Router --> AuthMid["AuthMiddleware
(Session & RBAC Guard)"] AuthMid --> CsrfCheck{"Validasi CSRF Token
(Khusus Request POST)"} CsrfCheck -- Valid --> Controllers["Controller Layer
(Ticket / Reply Controller)"] Router -- API Request --> ApiCtrl["ApiController
(Live Search & Badges)"] Controllers --> Services["Service Layer
(TicketService / ReplyService)"] ApiCtrl --> Services Services --> UploadUtil["FileUploader Util
(MIME check, 5MB, Rename)"] Services --> Models["Model & Database Layer
(PDO MySQL / SQLite)"] Models --> Controllers Controllers --> ViewResp["Render View HTML
(Mailbox Inbox Style)"] ApiCtrl --> JsonResp["Response JSON
(Search / Badge Polling)"]
Filter Keamanan File Upload (Anti-Malware & Webshell)

Lapisan sanitasi: verifikasi status error, batas kuota 5MB, deteksi magic bytes biner asli, dan pengacakan nama file.

flowchart TD InFile([Input File: $_FILES]) --> CheckEmpty{Ada File yang Diunggah?} CheckEmpty -- Tidak --> ReturnNull[Return null: Lanjut Tanpa Lampiran] CheckEmpty -- Ya --> CheckErr{UPLOAD_ERR_OK?} CheckErr -- Tidak --> ThrowErr1[Throw Exception: 'Gagal mengunggah file'] CheckErr -- Ya --> CheckSize{Ukuran File <= 5MB?} CheckSize -- Tidak --> ThrowErr2[Throw Exception: 'Ukuran file melebihi 5MB'] CheckSize -- Ya --> ReadMime[Baca Biner File Asli
via finfo_file / MAGIC BYTES] ReadMime --> WhitelistCheck{MIME di Whitelist?
image/jpeg, png, webp} WhitelistCheck -- Tidak --> ThrowErr3[Throw Exception: 'Format file tidak didukung'] WhitelistCheck -- Ya --> RandomName[Generate Nama Acak Unik
tkt_YYYYMMDD_His_hexrandom.ext] RandomName --> MoveFile[Pindahkan ke Folder uploads/
via move_uploaded_file] MoveFile --> MoveSuccess{Berhasil Dipindah?} MoveSuccess -- Ya --> ReturnName[Return Nama File Aman] MoveSuccess -- Tidak --> ThrowErr4[Throw Exception: 'Izin tulis folder gagal']
